\# Enterprise RAG Assistant



\## Overview



This project is a Retrieval-Augmented Generation (RAG) application built using Streamlit, ChromaDB, LangChain, and HuggingFace Embeddings.



\## Features

\- ChromaDB Vector Database

\- Semantic Search

\- Ollama Integration

\- Llama 3.2 Local LLM

\- AI Generated Answers

\- PDF Upload

\- Text Extraction

\- Text Chunking

\- ChromaDB Vector Storage

\- Semantic Search

\- Question Answering



\## Tech Stack



\- Python

\- Streamlit

\- LangChain

\- ChromaDB

\- HuggingFace Embeddings
